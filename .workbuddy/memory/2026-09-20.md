### 1）去点名只显示一个班的真正原因
`AttendancePage._loadStudents` 只取 `lesson.lesson.classId`（课表条目上的那**一个**班），
但课程管理里一门课可以勾选多个班级（`course_class` 多对多）→ 合班课只显示一个班的人。
- `CourseRepository.classIdsOfCourse(courseId)` 取课程挂载的全部班级；
- `StudentRepository.listByClasses(ids)` 取并集（`class_id IN (...)`，天然去重，按班级+id 排）；
- `_loadStudents` 用「课程的班级 → 空则回落 lesson.class_id」，并用已加载的列表；
- 配套测试：`database_repository_test.dart` group「合班课名单与每日考勤概览」——
  两班三人，`listByClasses` 出 3 人，而 `listByClass(first)` 少于 3（旧实现漏人）。

### 2）日历红点 → 考勤进度圆环（新文件 `lib/features/attendance/day_attendance_ring.dart`）
三种状态（用户规格）：无课 → 不画；有课无记录 → **透明描边圈**；有记录 → **红色圆弧**按百分比。
- 口径落在新模型 `AttendanceDayStat`（`hasLesson / expected / marked / present`）：
  `expected` = 当天每节课**课程全部班级**的学生数之和（与"去点名"名单同一口径），
  `marked` = 当天记录条数，`present` = 其中出勤条数；`rate = present / expected`（0~1 夹住）。
- **进度取的是"出勤率"不是"点名完成度"** —— 老师扫月历想看的是"哪天出勤不正常"，
  "哪天忘了点名"从透明圈就能看出来。若用户想改成完成度，改 `rate` 一个 getter 即可。
- 数据源 `AttendanceRepository.dayStats({from, to, teacherId})`：**两条聚合查询**覆盖整段
  区间（含月视图 42 天），SQL 里用 `COALESCE(NULLIF(子查询,0), lesson.class_id)` 兜住
  "课程一个班都没挂"的情况；没课也没记录的日子不塞进 map。
- 圆环**套在日期数字外面**（不另起一行），周视图/月视图共用；进度色 `tokens.nowLine`（红），
  轨道 `scheme.outlineVariant`；长按出 Tooltip（`attendanceRingNoRecord` / `attendanceRingRate`）。
- 考勤页用 `_dayStats`（key = "YYYY-MM-DD"）+ `_statsFrom/_statsTo` 缓存区间，
  同一月内切日期不重查；点名后 `_refreshRingStatsQuietly()` 立即重算
  （**统计失败只记日志**，否则会把"保存成功"报成"保存失败"）。

### 3）课表底色层次（用户："颜色太单调"）
- 课程格子：**斜向渐变底**（课程色 α0.17→0.07，展开时 0.26→0.13）+ **左侧 3~4px 色脊** +
  同色描边 + 展开时投影；**课程名居中**（`crossAxisAlignment.center` + `textAlign.center`）；
- 空格子：休息节次= `surfaceContainerHighest` 色带、今天那一列泛主色、
  **其余隔行深浅交替**（`surfaceContainer` / `surface`）——这就是"表格底"；
- 表头加 `surfaceContainer` 淡底 + 上圆角；格子用 `AppConstants.gridCellGap = 3` 的缝；
- **格子铺满整格**（`SizedBox.expand` 包住 cell body），否则每格缩成图标大小、中间全是空白；
- 底色只用 token 显式赋过值的两档（`surface` / `surfaceContainer`）：
  `surfaceContainerLow` 那几档是 Flutter 默认基线色（带紫灰），换到樱花粉/暖橙会脏。

### 7）踩坑：过冲曲线 + BoxShadow.lerp = 断言崩溃（真实隐患）
选课卡片原先写 `AnimatedContainer(curve: AppMotion.softSpring)`，动的是
描边/阴影/渐变 —— `softSpring` 是 `Cubic(0.2,1.25,0.4,1)` **会过冲**，
插值参数 >1 后 `BoxShadow.lerp` 把 `blurRadius` 算成负数，dart:ui 直接抛
`Text shadow blur radius should be non-negative`（debug 崩，release 渲染不可预期）。
**规则：位移/缩放才用 spring/expressive；颜色、描边、阴影、透明度必须用单调的
`AppMotion.effects`。** 已写进 skill `flutter-quality-gates`。

### 8）踩坑：位图断言必须走 tester.runAsync
想"数像素"验证圆环（透明 / 淡描边 / 红弧）时用 `Picture.toImage`，
在 `test()` 或普通 `testWidgets` 的伪异步时钟下会挂到 10 分钟超时。
改成 `await tester.runAsync(() => _paint(...))` 立刻通过。
断言口径：`r>140 && r>b+60 && g<r` 判红；全透明像素数、红色像素数三态可分（50% < 全勤×0.75）。
