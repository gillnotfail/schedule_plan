## 顺带记录的诊断技巧
- Git Bash 里调 Windows 原生命令，`/FO` 这种参数会被 MSYS 改写成路径（`C:/Users/.../FO`）；
  要用 `//FO` 双斜杠。
- `tasklist` 输出是 GBK，Python 里 `sys.stdin.buffer.read().decode('gbk', errors='replace')` 才不炸。
- PowerShell 工具在本机管道紧张时**会静默吞掉 stdout**（只回 "Command completed with exit code 0"），
  出现这种"命令成功但没输出"就先去想管道问题。
