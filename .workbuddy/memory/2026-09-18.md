## 顺带修掉的两个真实缺陷

1. `TemplateRepository.saveWeekdayPeriods` 原来是「先校验、后重排序号」。
   界面删行后传入的旧序号是乱序/带空洞的，校验器按旧序号排序会误判 notAscending。
   改为**先按录入顺序重排再校验**。
2. `DateUtils.tryParseDate` 原来直接 `DateTime.tryParse`，会把 `2026-02-30` 进位成 `2026-03-02`。
   改为解析后回校 year/month/day，不一致则拒绝（考勤日期必须是用户真正选的那天）。

## 第二轮：Material 3 Expressive 改造 + 重写课表页 / 考勤页

### 版式改动

- **课表页**改成「默认表格视图」：第一行星期、第一列节次+时间，点第一列的节次即可改时间
  并顺延后续；右上角两个入口 = 作息切换（PopupMenu，多套作息互切）+ 课表设置
  （一键生成作息 / 默认作息修改 / 一键清空 / 拍照导入）。聚合时间轴降为第二视图。
- **考勤页**改成「默认周视图」日历（右上角切月）+ 当日课程 Chip 横滑条 +
  紧凑三列表格（姓名/学号/考勤），**三列表头都带双三角排序**，排序方式与方向都持久化到
  `SettingKeys.studentSortMode` + `SettingKeys.studentSortDescending`。

### 一致性收敛

- 全 App 的动效 token 统一收到 `AppMotion`，删掉了 `AppConstants` 里与它重复的
  `pressAnimation` / `pulseDuration` / `heroTransition` / `wheelSnapAnimation` 四个常量。
- `ScaleTap` 的松开曲线从 `Curves.easeOut` 换成 `AppMotion.softSpring`（M3E 要有回弹手感）。
- 出厂作息统一到 `DatabaseSchema.generatePeriodRows` 一个入口；新建模板自带默认作息。

### 顺手修掉的三个真实缺陷

1. **日历翻月溢出**：原来直接 `DateTime(y, m-1, d)`，3/31 点「上一月」会跳到 3/3
   （Dart DateTime 溢出进位）。新增 `DateUtils.shiftMonth` 把日收敛到目标月最后一天，
   补了 3 个用例（含闰年 2/29、跨年）。
2. **高风险学生检测竞态**：原来用 `_riskPending` 布尔做互斥，切换班级时新一次计算
   会被直接跳过，导致新班级的高风险标记永远补不上。改成世代号 `_riskToken` 作废旧计算。
3. **`(_, __)` → `(_, _)`**：新 Dart 版本的双下划线 lint，全库批量替换。
