## 需求（用户原话要点）

- 学生一旦点成休学或免修后就改不回来（bug）。
- 休学确实不大会来：排到最后没问题；但**再点这个学生的状态应弹「该学生已休学，是否复学」**，选复学→恢复，否则取消。
- 免修可能回来上课、也可能迟到早退：免修应**支持多个状态 / 多选**（即免修不是排他的，日常点名照常）。

## 结论与方案（第 16 轮定稿）

**休学 ≠ 免修**：

- **休学（suspended）= 完全不来**：锁死日常五态**与免修胶囊**；唯一出口是再点休学胶囊 → 「复学」确认
  （`attendanceResumeTitle/Body/Confirm`，非 danger 按钮，confirmLabel=复学）。
- **免修（exempt）= 免修这门课但仍会来**：**只作角标、不锁**；迟到早退照常标；免修与日常状态可同时高亮。

## 环境事故：Windows 命名管道耗尽（重要，会再次遇到）

本机 flutter 全线崩溃，报错 **`CreateFile failed 231 (所有的管道范例都在使用中)`**，出现在任何 Dart 子进程 spawn 处：
`git log`（版本检查）、`dart format`（gen-l10n 收尾）、`cmd /c ver`（analytics）、`dartaotruntime`（analysis server）、
`adb`。连 **PowerShell 工具的输出捕获也变空**（它自己也走管道）。

排查记录（供下次）：
- `tasklist` 无残留 dart/flutter；杀了孤儿 cmd/conhost 仍无效 → 是**内核命名管道泄漏**，杀进程不回收，**需重启**。
- **`dart format` 是进程内运行、不走子进程**，所以能跑、还能顺带验语法（`Formatted 3 files` 即语法通过）。这是本轮
  唯一能用的「编译级」校验：用它确认了改动文件语法无误、并把 gen-l10n 没格式化的生成文件补了格式。
- `flutter --no-version-check` 只能跳过 `git log` 那一步，挡不住后面 spawn 的崩溃。
- 绕过沙箱（`dangerouslyDisableSandbox`）无效 → 不是沙箱问题。
- 结论：`flutter analyze` / `flutter test` 本轮**没能跑**（都被子进程 spawn 卡死）。**重启后必须补跑门禁**。
